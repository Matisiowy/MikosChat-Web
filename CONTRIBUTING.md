# Contributing to MikosChat

Thank you for your interest in contributing!

## Getting started

1. Fork the repository.
2. Clone your fork.
3. Install dependencies with npm ci.
4. Create a feature or bugfix branch.
5. Implement and test your changes.
6. Open a pull request.

## Development guidelines

- Use TypeScript.
- Follow the existing project structure.
- Keep changes focused and maintainable.
- Include tests where appropriate.
- Verify that the project builds successfully.
- Never commit credentials or personal data.
- Use isolated environments for integration tests.

## Commit messages

Conventional commits are encouraged:

- feat: add a feature
- fix: resolve a bug
- docs: update documentation
- refactor: improve existing code
- test: add or update tests
- chore: maintenance changes

## Licensing

Contributions must be compatible with AGPL-3.0-only.
